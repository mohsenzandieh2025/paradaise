این پنل رو من از صفر نوشتم. نه کلون یک پروژه آماده است، نه کپی از جای دیگه. هدفم این بود که یک پنل مدیریت پروکسی و VPN داشته باشیم که هم سبک باشه، هم امن، و هم نیازی به هزار تا کانفیگ پیچیده نداشته باشه. این پروژه رو به دو زبان نوشتم که شما بر اساس نیازتون انتخاب کنید:
۱. **نسخه پایتون:** برای کسانی که می‌خوان در ۵ دقیقه روی یک سرور اوبونتو پنل رو بالا بیارن.
۲. **نسخه Go:** برای کارهای حرفه‌ای‌تر، معماری چند لایه و مدیریت متمرکز چند سرور.

## 📖 آموزش نصب (نسخه پایتون)

نصب این نسخه خیلی راحته. فقط کافیه با SSH به سرور اوبونتوت وصل بشی (من معمولا از Termius یا JuiceSSH روی گوشی هم استفاده می‌کنم). 

**قدم اول:** پوشه پروژه رو روی سرور بساز یا کلون کن.
**قدم دوم:** فایل `install.sh` رو با دستور زیر اجرا کن:

```bash
sudo bash install.sh
```

اسکریپت خودش پایتون، Xray و تمام پیش‌نیازها رو نصب می‌کنه. وقتی تموم شد، یه رمز عبور بهت میده. آدرس سرورت رو با پورت 8000 توی مرورگر بزن و وارد شو. تمام.

---

⚠️ خطاهای رایج و راه‌حل‌شون

من توی این سال‌ها یاد گرفتم که سرور همیشه باگ‌های عجیب نداره، گاهی ما یه چیزی رو ساده اشتباه می‌کنیم. این‌ها خطاهایی هستن که ممکنه موقع نصب ببینی:

۱. ارور پیدا نکردن آی‌پی (Could not auto-detect server IP)

موقع نصب، بعضی وقتا اسکریپت گیر می‌کنه و یه آی‌پی داخلی مثل 172.x.x.x نشون میده. این یعنی سرورت پشت یک لایه شبکه (مثل Docker) هست و اسکریپت نمی‌تونه آی‌پی اصلی رو ببینه.
راه‌حل: هیچی رو تایپ نکن، اول Ctrl+C بزن. بعد توی ترمینال این دستور رو بزن:

```bash
curl -4 ifconfig.me
```

هر عددی که بهت داد، اون آی‌پی عمومی (Public) سرورت هست. اسکریپت رو دوباره اجرا کن و همون عدد رو دستی وارد کن.

۲. سرویس پنل بالا نمیاد (Connection Refused)

اگر آدرس پنل رو زدی و خطا داد، اول از همه مطمئن شو فایروال (Firewall) پورت ۸۰۰۰ رو باز کرده. با دستور ufw allow 8000/tcp این کار رو انجام بده. اگر بازم درست نشد، وضعیت سرویس رو با این دستور چک کن:

```bash
systemctl status paradise-panel
```

اگر نوشته Failed، یعنی یه جای کد مشکل داشته. لاگ رو با این دستور بخون تا دقیقا بفهمی چی شده:

```bash
journalctl -u paradise-panel -n 30 --no-pager
```

۳. پورت ۸۰۰۰ اشغاله (Port already in use)

خیلی وقتا سرور روی پورت ۸۰۰۰ یه چیز دیگه (مثل یه بات یا یه سرویس جانبی) داره اجرا می‌کنه. 
راه‌حل: برو فایل install.sh رو باز کن و هرجا عدد 8000 بود (مثلا --port 8000 یا ufw allow 8000)، عوضش کن به 8080 یا هر پورت دیگه‌ای که خیالت تخت باشه آزاده.

۴. گواهی SSL (Let's Encrypt) ارور میده

اگر موقع نصب گزینه دامنه رو انتخاب کردی و ارور داد، ۹۹ درصد مشکل از DNS هست. چک کن که رکورد A توی پنل دامنه‌ت، به آی‌پی سرورت وصل باشه. اگر تازه DNS رو تنظیم کردی، ممکنه چند ساعت طول بکشه تا پروپاگیت بشه. برای تست کردن بدون دامنه، موقع نصب گزینه Skip SSL رو انتخاب کن تا با http بالا بیاد.
