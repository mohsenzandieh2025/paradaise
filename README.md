# paradaise
# 🌐 پنل مدیریت پارادایس نت (Paradise)سلام. من محسن زندیه هستم. از سال ۱۳۸۲ که با وبلاگ‌نویسی و هک و نفوذ شروع کردم تا امروز که مدیر شرکت پارادایس نت هستم، همیشه دلم می‌خواست ابزارهایی بسازم که کار رو برای بقیه راحت‌تر کنه.   این پنل رو من از صفر نوشتم. نه کلون یک پروژه آماده است وبرای این پنل ماه ها و ساعت ها وقت گزاشتم پس خاهشن استارکن پروژه رو
